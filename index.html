About
Systems engineer · Militia Capital (long/short equity fund)

What I Do

I build and run the automation at Militia Capital: the portal our investors log into, the screener the desk uses to find shorts, the tool that builds our regulatory filings, the monitors that track the SEC, and the pipeline that rebuilds our marketing materials from live fund data every month.

All of that used to be somebody's recurring manual work. Now it runs on a schedule and gets audited. When something at the firm still needs a person doing it by hand every week, that usually becomes my next project.

How I Work

  • I ship complete systems solo: ingest, scoring, UI, deployment, docs.
  • I write the spec first. PRDs, phased plans, and coverage matrices before code.
  • I check data against independent sources and keep changelogs for everything.
  • I keep LLM costs low without giving up output quality.
  • I know the regulated side of finance: SEC filings, marketing review, records retention, investor onboarding.
Process
How I build, on every project. The commit histories show it.
01

Spec

The PRD comes before the code: sources listed, edge cases listed, success criteria written down. The plan lives in the repo.

02

Pipeline

A deterministic core, LLM stages only where judgment is needed, and retry logic throughout. Everything is built to run on a schedule without supervision.

03

Audit

Outputs get reconciled against independent sources. Coverage matrices, feed-versus-feed verification, changelogs checked against actual renders.

04

Ship & Harden

Deployed on Vercel or Render with real auth, idempotent actions, spend caps, and handoff docs so someone else can take over.

Data quality

Found and fixed the bad data under the screener.

The screener's stock database was polluted: nearly 7,800 funds and trusts were being treated as operating companies, and a ticker-format bug had silently dropped 689 real ones. I audited every data source we ingest, purged the junk, recovered the lost companies, and checked our short-borrow data against outside references. The screen went from noisy to trustworthy.

Cost engineering

Cut LLM spend about 85% with a cross-checked two-model stack.

The backtester's classification runs on a cheap primary model. A stronger model spot-checks samples for drift and a gap backstop catches misses, so quality holds while per-run cost drops to a fraction. Every run also carries its own spend cap.
